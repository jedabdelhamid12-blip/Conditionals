02 / Learn the rules

Four types. Four easy rules.

Read each meaning, formula, and example. The formula tells you which verb form to use.

Quick way to choose

Zero: Always / generally true

If you heat ice, it melts.

First: Possible future

If I study, I will pass.

Second: Imagine now or later

If I had more time, I would study.

Third: Imagine a different past

If I had studied, I would have passed.

STEP exam tip: In ordinary first conditionals, write if + present, not if + will. In second and third conditionals, do not put would in the if-clause.

The four types at a glance

TypeFormulaUseExample
ZeroIf + present simple, present simpleFacts / habitsIf water freezes, it becomes ice.
FirstIf + present simple, will + base verbPossible futureIf I study, I will pass.
SecondIf + past simple, would + base verbImaginary present / futureIf I had a car, I would drive.
ThirdIf + past perfect, would have + V3Imaginary pastIf I had left early, I would have arrived on time.

Common STEP mistakes

First conditional

Correct: If it rains, we will stay home.
Incorrect: If it will rain, we will stay home.

Second conditional

Correct: If I were you, I would study.
Do not use would immediately after if.

Third conditional

Correct: If she had called, I would have answered.
Both the condition and the result refer to the past.

Comma rule

If you study, you will pass.
You will pass if you study.
The comma usually follows an opening if-clause.
